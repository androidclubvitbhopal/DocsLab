# Android Development Learning Path

## Overview

This roadmap guides you from a complete beginner to an advanced Android developer using modern tools and best‑practice architectures. Each section includes a brief description, key concepts, and recommended resources (official docs, tutorials, and sample projects).

---

## 1️ Getting Started

### 1.1 Install Android Studio

- Download the latest stable version from the [Android Studio website](https://developer.android.com/studio).
- Set up the IDE, SDK manager, and a virtual device (AVD).

### 1.2 Kotlin Basics

> **Why Kotlin?** Concise syntax, null‑safety, coroutine support.

- **Core Topics:** Variables (`val`, `var`), data types, Functions, extensions, Classes, inheritance, sealed classes, Collections, lambda expressions, and Coroutines (basic `launch`, `async`).
- **Resources:** [Kotlin docs](https://kotlinlang.org/docs/home.html) and Android Kotlin Fundamentals (codelab).

## 2️⃣ Building UI with Jetpack Compose

### 2.1 Compose Fundamentals

- Composable functions and the `@Composable` annotation.
- State handling using `remember` and `mutableStateOf`.
- Layouts including `Column`, `Row`, `Box`, and `LazyColumn`.
- Theming with `MaterialTheme` and dark mode.

Here is a basic example of how to build a Compose UI component:

```kotlin
@Composable
fun Greeting(name: String) {
    Text(text = "Hello $name!")
}
```

### 2.2 Advanced Compose

- **Navigation component** (`NavHost`, `composable` destinations)
- **Animations** (`animate*AsState`, `Transition`)
- **Custom drawing** with `Canvas`
- **Testing UI** with `compose-test`
  Here is an example of an advanced feature—adding smooth animations with just a few lines of code:

```kotlin
@Composable
fun ExpandableCard(title: String, body: String) {
    var expanded by remember { mutableStateOf(false) }

    Column(modifier = Modifier.padding(16.dp).clickable { expanded = !expanded }) {
        Text(text = title, style = MaterialTheme.typography.titleLarge)

        // This automatically animates the text appearing and disappearing
        AnimatedVisibility(visible = expanded) {
            Text(text = body, modifier = Modifier.padding(top = 8.dp))
        }
    }
}
```

**Resources:**

- Official Compose tutorial: https://developer.android.com/jetpack/compose/tutorial

## Architecture – MVVM + Clean Architecture

### 3.1 MVVM Overview

- **Model:** Repository & data sources
- **View:** Compose UI (stateless)
- **ViewModel:** `androidx.lifecycle.ViewModel`, `LiveData`/`StateFlow`
- Here is a standard example of a modern ViewModel exposing state to the UI:

```kotlin
@HiltViewModel
class TodoViewModel @Inject constructor(
    private val repository: TodoRepository
) : ViewModel() {

    // Internal mutable state
    private val _uiState = MutableStateFlow<List<Todo>>(emptyList())
    // Exposed read-only state for Compose
    val uiState: StateFlow<List<Todo>> = _uiState.asStateFlow()

    fun fetchTodos() {
        viewModelScope.launch {
            _uiState.value = repository.getAllTodos()
        }
    }
}
```

### 3.2 Dependency Injection

- Hilt (`@HiltAndroidApp`, `@Inject`, modules)
- Scoping ViewModel lifecycles

### 3️⃣ Clean Architecture Layers

- Domain (use‑cases), Data (repositories), Presentation (ViewModel)
- Benefits: testability, separation of concerns

## Networking & Data Persistence

### 4.1 Retrofit + Kotlin Coroutines

- Define API interfaces, `@GET`, `@POST`
- Use `suspend` functions for async calls
- Error handling with `Result` or sealed classes
- Defining a network call with Retrofit is as simple as creating an interface:

```kotlin
interface WeatherApiService {
    @GET("data/2.5/weather")
    suspend fun getCurrentWeather(
        @Query("q") cityName: String,
        @Query("appid") apiKey: String
    ): WeatherResponse
}
```

### 4.2 OkHttp Interceptors

- **Logging:** Use `HttpLoggingInterceptor` to see request and response data (URLs, headers, JSON bodies) directly in Logcat. This is essential for debugging API issues.
- **Authentication:** Create custom interceptors to automatically attach API keys or Bearer tokens to every single outgoing request so you don't have to add them manually each time.

Here is how you set up an OkHttp client with a logging and auth interceptor to pass into Retrofit:

```kotlin
// 1. Create a logger
val loggingInterceptor = HttpLoggingInterceptor().apply {
    level = HttpLoggingInterceptor.Level.BODY
}

// 2. Build the client with interceptors
val okHttpClient = OkHttpClient.Builder()
    .addInterceptor(loggingInterceptor)
    .addInterceptor { chain ->
        // This adds an Auth header to every request automatically
        val request = chain.request().newBuilder()
            .addHeader("Authorization", "Bearer YOUR_TOKEN_HERE")
            .build()
        chain.proceed(request)
    }
    .build()
```

### 4.3 Data storage

- Room database (entities, DAO, migrations)
- DataStore (preferences)
- Offline‑first strategy with Repository pattern
- Here is how you define a table in a Room database using a simple Kotlin data class:

```kotlin
@Entity(tableName = "transactions")
data class Transaction(
    @PrimaryKey(autoGenerate = true) val id: Int = 0,
    val amount: Double,
    val description: String,
    val date: Long
)
```
